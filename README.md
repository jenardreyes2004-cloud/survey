# Quick Survey

A playful, single-page survey with an animated mascot. Built with plain HTML/CSS/JS — no build step, no dependencies.

## Deploy on Vercel

1. Push this repo to GitHub, GitLab, or Bitbucket.
2. Import the repository in [Vercel](https://vercel.com).
3. Vercel detects the static HTML and deploys it automatically.
4. Your survey goes live at the root URL (configured in `vercel.json`).

## Local preview

Open `quick-survey.html` directly in your browser, or serve it with any static server:

```bash
npx serve .
# or
python -m http.server 8000
```

## Project structure

```
quick-survey.html  # the survey (HTML + CSS + JS, self-contained)
vercel.json         # Vercel deployment config
README.md           # this file
```
